# ChatGPT Quota Widget

这是 `baiyeyshsbsu` 维护的 Windows 桌面额度悬浮组件。主界面读取本机 ChatGPT/Codex
当前登录账号的实时额度；账号列表从 Sub2API 读取服务器账号的 7 天额度快照。

## 当前功能

- 显示 7 天或 5 小时剩余额度、重置时间和套餐类型
- 红、黄、绿状态提示与手动刷新
- 在个人主页切换“个人使用”与“中转站”模式
- 个人与中转站模式都可独立切换 7d/5h 额度窗口
- 个人模式自动识别本机 ChatGPT/Codex 当前登录账号
- 中转站模式按当前 7d/5h 窗口汇总所有服务端账号剩余额度，3 个满额账号显示为 300%
- 连接 Sub2API 后同步所有 OpenAI OAuth 账号
- 服务端额度只读展示，不允许在小组件中人工修改百分比
- 每页最多显示 5 个账号，窗口高度随账号数量变化
- 主界面每 2 分钟通过本机 Codex 获取一次当前账号额度
- 中转站账号及总额度每 5 分钟读取一次 Sub2API
- 中转站模式启动时自动用系统浏览器打开已保存的 Sub2API 地址
- 列表中的“刷新此账号”和“强制刷新”可触发服务端主动额度探测
- 窗口置顶、关闭时隐藏到系统托盘，仅托盘菜单执行彻底退出
- 区分 Sub2API 网络、登录和服务响应错误，临时失败时保留最后读数
- 续费提醒：手动添加需要自己充值的订阅项目，到期前 3 天（可调）主界面信标爆红并弹窗提醒；
  点「已续费」按周期自动顺延（默认 +30 天），也可以在「个人主页 → 续费提醒」中手动修改到期日期、
  周期、金额与付款页链接；托盘图标同步变色并弹出系统气泡
- 中文和英文界面

本项目仅在用户手动启动时运行。

## 本地运行

```powershell
npm install
npm start
```

也可以直接双击项目根目录的 `start.bat`。

先运行桌面的 `查看服务器状态.bat` 建立 SSH 隧道。首次打开“账号管理”，
填写 Sub2API 地址（当前服务器隧道默认 `http://127.0.0.1:18080`）、
管理员邮箱和密码。管理员密码不会保存；
访问令牌和刷新令牌通过 Electron `safeStorage` 使用 Windows 系统能力加密保存。

## 打包

```powershell
npm run build
```

便携版输出到 `dist` 目录。

## 数据与隐私

Sub2API 地址和加密后的登录令牌保存在 Electron 的本机
`userData/sub2api-auth.json` 中；管理员密码不会落盘。主界面账号由本机 Codex
登录态自动决定，不保存人工选择。续费提醒数据（项目名称、到期日、金额、付款页链接）
单独保存在本机 `userData/subscriptions.json` 中，不与账号数据混存。额度数据不会由本项目上传到其他第三方服务。
